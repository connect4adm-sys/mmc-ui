# My Mentor Circle (MMC) UI

Official frontend web experience for **My Mentor Circle (MMC)** — Connecting Schools, Students, Universities, and Educational Partners.

## 🚀 Overview

- **Homepage (`index.html`)**: Conversion-optimized, school-first platform presentation featuring the 3D ecosystem island visualization, 4 core school benefits, real-world case stories (Kolkata Career Fair, BLS World School), student development roadmap, 6 distinct event formats, and university/partner discovery channels.
- **Event Gallery (`gallery.html`)**: Editorial multimedia gallery showcasing authentic campus interactions, featuring:
  - **Motion Blur Portfolio Showcase** in the hero section.
  - **WebGL2 Splash Cursor** fluid simulation ink trails.
  - Interactive category filter tabs (All Moments, Career Fairs, STEM & Workshops, Leadership & MUN, Campus Life & Contests).
  - High-resolution photography and fullscreen lightbox modal with keyboard navigation.

## 🛠️ Tech Stack

- Semantic HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid, 3D Transforms, Backdrop Filter).
- Pure Vanilla JavaScript (ES6+, zero external build steps or heavy dependencies).
- WebGL2 fluid dynamic shaders with Navier-Stokes physics.
- Responsive design tailored for mobile, tablet, and high-resolution desktop viewports.
